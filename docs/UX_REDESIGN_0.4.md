# Nexvary Panel 0.4 UX Redesign

Goal: move from a long dashboard to a premium workspace with screen-level navigation and contextual actions.

Principles:
- One primary workspace screen at a time.
- Persistent sidebar + command bar.
- Large original SVG icons with functional color coding.
- Rich application/server cards instead of raw tables.
- Contextual create/action panels per screen.
- Desktop + mobile release gates for every workspace screen.
- No changes to privileged backend behavior without separate security review.
