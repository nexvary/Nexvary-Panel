Safe Change Lifecycle: Preview → Step-Up → server-side revalidation → bounded privileged action → post-check → audit. System Updates require an unchanged package-plan fingerprint before Apply; Hostname verifies current state and restores the previous hostname if its post-check fails. Package upgrades are deliberately not auto-downgraded after execution because blind package rollback can make the host less recoverable. Reboot remains preview-only and is never executed from the browser. No command, argv, terminal, or free-form root shell is accepted by this control plane.
